# 🔥 STREAKS

A minimalist habit tracker PWA. No fluff, no gamification — just habits and streaks.

## Features

- **Add habits** with name + emoji
- **Daily check-in** — tap to mark complete
- **Streak counter** — current streak with 🔥
- **21-day dot calendar** — visualize your consistency
- **Dark/light mode** — system-aware toggle
- **Offline-first** — full PWA with service worker
- **No backend** — localStorage persistence

## Stack

- React 18 + TypeScript
- Vite + vite-plugin-pwa
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deploys to GitHub Pages via `gh-pages` branch.
